# masanin
[masanin.kr 프로젝트 설명]  'masanin.kr' 프로젝트는 저만의 디지털 정체성을 구축하기 위한 개인 홈페이지 제작 프로젝트입니다. 이 저장소는 사이트의 모든 소스 코드를 체계적으로 관리하는 공간입니다.  주요 목적은 저의 기술적 역량을 보여주는 포트폴리오 전시와 학습한 내용을 기록하는 기술 블로그 운영입니다. HTML5와 CSS3를 기본으로 하여 깔끔하고 직관적인 디자인을 구현하는 것을 목표로 합니다. 깃허브 페이지(GitHub Pages)를 활용해 호스팅하며, 구매한 masanin.kr 도메인을 연결하여 전문적인 웹사이트로 완성해 나갈 예정입니다.
